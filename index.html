🧩 If… Los conditionals en inglés

Una guía para entenderlos y un gimnasio para practicarlos.

La idea clave

Un conditional tiene dos partes:

IF + situación (la condición), resultado

Lo que decide qué tiempo verbal usar es qué tan real o posible es la situación. Cuanto más irreal o más lejos en el tiempo, más “retrocedemos” el verbo:

¿Qué tan real es?Tiempo después de if
Siempre es verdadPresente
Puede pasar (futuro real)Presente
Imaginario ahoraPasado simple
Imaginario en el pasado (ya no se puede cambiar)Past perfect
💡 Por eso aparecen el pasado y el past perfect: no son tiempos pasados de verdad, son “tiempos de imaginación”.

Tipo 0 · Hechos y cosas que siempre pasan

If + presente, presente
If you heat ice, it melts.Si calentás hielo, se derrite.
If I don't sleep, I get grumpy.

Se puede cambiar if por whenever y significa lo mismo.

Tipo 1 · Posibilidad real en el futuro

If + presente, will + verbo
If it rains tomorrow, we will stay home.
If you study, you will pass the exam.
⚠️ Error clásico: ❌ If it will rain… → ✅ If it rains…
Después de if nunca va will.

Acá aparece el present perfect

En el tipo 1 también se puede usar present perfect después de if, para decir “cuando ya haya terminado esto”:

If you have finished your homework, you can play.Si ya terminaste la tarea, podés jugar.
If she has left already, we will call her.
Es un tipo 1 con una acción ya completada. El present perfect NO es un tipo de conditional aparte.

Tipo 2 · Imaginario en el presente o futuro

If + pasado simple, would + verbo
If I had a million dollars, I would buy an island.No tengo el dinero.
If I were you, I would apologize.
⚠️ Dos trampas:
1. Aunque el verbo esté en pasado, habla del presente o futuro. No pasó nada ayer.
2. Con I / he / she / it se usa were: If I were…, If she were… (en conversación informal también se oye was, pero were es lo correcto).

Tipo 3 · Imaginario en el pasado

If + past perfect, would have + participio
If I had studied, I would have passed.Pero no estudié y no aprobé.
If we had left earlier, we wouldn't have missed the bus.

Se usa para lamentos y para “qué hubiera pasado si…”. Ya no se puede cambiar.

¿Cuál uso? Tres preguntas

Ojo con las contracciones: I'd puede ser I would (en el resultado) o I had (después de if).

Los 4 errores más comunes

❌ Mal✅ BienPor qué
If I will see him, I'll tell him.If I see him, I'll tell him.Nunca will después de if.
If I would have money, I'd buy it.If I had money, I'd buy it.Nunca would después de if.
If I studied harder, I would have passed.If I had studied harder, I would have passed.Pasado = tipo 3, necesita past perfect.
If I was you…If I were you…Con if imaginario, were.
